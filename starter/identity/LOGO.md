# 게임 심벌 후보 만들기

게임 제목용 심벌·파비콘을 요청할 때 이 절차를 읽는다. 게임 기획·씬 제작과 별도로 수행하는 정적 벡터 작업이다. 채팅이 제작과 선택을 소유한다.

1. 프로젝트의 원문 브리프에서 정확한 제목, 게임 행동, 분위기, 쓸 크기와 배경을 뽑는다. 없는 정보는 가정으로 적는다.
2. 서로 다른 구조의 후보 세 개를 만든다. 이 폴더의 초승달·표적·로봇 SVG는 비교용 원본 예시다. 새 게임에 복사할 때 원본 경로와 실제 복사 사실을 기록하며, 기존 유명 로고나 폰트 도안을 옮기지 않는다.
3. SVG는 정적 도형만 쓴다. 이 예시는 svg/path, 고정 fill, viewBox, width/height, d, fill-rule만 사용한다. 외부 참조·스크립트·폰트·래스터·필터·엔티티는 허용하지 않는다. 실제 XML 파싱으로 요소와 속성을 확인한다.
4. 로컬 SVG 래스터라이저로 각 후보를 16/32/128px PNG로 만든다. 밝고 어두운 배경의 역상 단색을 함께 놓되, 이미지를 확대하지 않은 비교 시트를 직접 본다. 파일 생성 성공과 시각적 가독성을 별도로 보고한다.
5. 후보별 한 줄 의도, 작은 크기 관찰, 오독 가능성, 임시 선호와 한계를 남긴다. 선호는 자동 채택이 아니다. 사람의 선택이 없으면 파비콘·런타임·기존 에셋을 교체하지 않는다.
6. 프로젝트의 `identity/`에 원본 SVG, PNG, 시트, 검증 결과와 노트를 둔다. 실제 입력·생성물·검증을 프로젝트 그래프의 `record` 경로로 연결한다. 이 문서는 실행 기록을 대신하지 않는다.

최소 납품은 세 후보와 비교 근거다. 선택된 방향의 전체 브랜드 키트는 별도 요청 범위다. 심벌 SVG에는 글자가 없으며 한글 제목 조판은 소비 화면이 소유한다. 상표·유사성 검토와 실제 브라우저 탭 검토는 별도의 근거가 필요하다.

방법 참고는 [logo-design SKILL.md](https://github.com/kaankiziltug/logo-design-skill/blob/main/skills/logo-design/SKILL.md)다. 2026-11-08에 현재 본문의 브리프, 세 가지 대안, 원크기 렌더 후 관찰 절차를 확인했다. 이 로컬 절차와 도형은 새로 작성했으며 원문의 로고 라이브러리·템플릿·폰트·스크립트를 복제하지 않았다. 실행 시 네트워크나 외부 스킬 설치가 필요하지 않다.
